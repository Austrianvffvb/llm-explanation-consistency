# Attribution and release scope

This project adapts the BBQ explanation-consistency experiment from:

Miles Turpin et al., *Language Models Don't Always Say What They Think: Unfaithful Explanations in Chain-of-Thought Prompting*, 2023.

Paper: https://arxiv.org/abs/2305.04388
Code: https://github.com/milesaturpin/cot-unfaithfulness
Source revision: df099452736946533f59498a90c23be3f09631c4

The upstream MIT license and copyright notice are retained in LICENSE. The evaluation methodology and upstream data/prompts are not original contributions of this project. Additional code and documentation in this repository are released under the same MIT terms, copyright (c) 2026 Qiziheng.

Original BBQ: https://github.com/nyu-mll/BBQ . Dataset and third-party content remain subject to their respective terms; the code license does not independently grant rights over those datasets. This release provides source identifiers and checksums rather than redistributing benchmark text, demonstrations, or raw API outputs.

The public per-pair artifact contains answer letters and evaluation metadata only. Full responses, request logs, local paths, credentials, virtual environments, unrelated projects, and BBH pilot results are not part of this release.
